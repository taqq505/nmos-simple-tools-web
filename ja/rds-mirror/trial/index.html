スクロールで進むチュートリアル(試作)

左のテキストをスクロールすると、右側の画面が自動で切り替わります。

Flow 01 — 起動直後

Dashboardで全体を把握する

起動すると最初に表示されるのがDashboardです。登録済みのRDS、実行中のジョブ、ミラー済みリソース数が一目で分かります。

Flow 02 — RDS Registry

ミラー元・先のRDSを登録する

左サイドバーの RDS Registry から2つのレジストリを登録します。Query API URLとRegistration API URLを入力してSaveするだけです。

Flow 03 — Mirror workspace

そのままの構造でミラーする(Passthrough)

SOURCEとDESTINATIONを選び、コピーしたいリソースをクリックして Copy selection を押すだけで、同じ構造のまま右側に登録されます。

Flow 04 — Transform config

宛先IP/portを書き換える(Transform)

接続線のアイコンから設定パネルを開き、Transformタブで宛先IP/portを入力。保存前にSDPをプレビューして確認できます。

Flow 05 — Resource detail

出自をダブルクリックで確認する

どの行もダブルクリックすれば、ネイティブか他RDSからのミラーかがバッジで分かり、生のJSONも確認できます。

Flow 06 — Chain-mirror guard

連鎖ミラーを防ぐ

ミラーされてきたリソースはさらに別のRDSへミラーできないようブロックされ、クリックすると理由を説明するトーストが出ます。
