概要

2つのレジストリをつなぐミラーリングエンジン

NMOS Simple RDS Mirrorは、独立した2つのNMOSレジストリ間で、選択したIS-04センダー/レシーバーを継続的にミラーリングするツールです。リソースをそのまま複製する「Passthrough」と、宛先ごとのプロキシノード経由でマルチキャストアドレスやラベルを書き換える「Transform」を、リソースごとに選択できます。扱うのはあくまで制御プレーンのメタデータのみで、実際の映像/音声ストリームはこのツールを経由しません。

大規模レジストリのページネーションの癖やWebSocket切断への耐性など、実運用で遭遇しがちな問題に対応した設計です。ヘッドレス(Node.js単体)でもElectronデスクトップアプリとしても動作します。

主な機能

  • Passthrough / Transformをリソースごとに選択 — Transformは独自のIS-05 Connection APIを持つプロキシノード経由
  • 依存関係クロージャの解決(sender→flow→source、device→node)と参照カウント方式の登録管理
  • 大規模・実運用レジストリの癖に強い設計(双方向ページネーション、WebSocket自動再接続)
  • 3ペイン(ソース/接続/宛先)のMirrorワークスペース、リソースごとの詳細ドリルダウン
  • 連鎖ミラーガード(オプション)、繰り返し障害を追跡するErrorsページ
  • ヘッドレス(node core/server.js)でもElectronでも動作 — トレイ常駐・Windows自動起動対応

クイックスタート

ミラージョブを作成する

01

ダウンロードして起動

GitHub Releasesページからポータブル.exeを取得してダブルクリック。ヘッドレスで使いたい場合はnpm run coreでも起動できます。

02

ソース/宛先レジストリを登録

ミラー元とミラー先、それぞれのNMOS Query APIエンドポイントを登録します。

03

ミラーするリソースを選択

Sourceペインでセンダー/レシーバーを選び、Passthrough(そのまま複製)かTransform(アドレス/ラベル変換)かを指定します。

04

ジョブを実行して監視

Destinationペインでミラー結果を確認。問題が起きた場合はErrorsページに残り続けるので見落としません。

注意点

導入前に知っておきたいこと

初回起動時にファイアウォールの許可が必要

WindowsがNMOS Simple RDS Mirror.exeの通信許可を尋ねるダイアログを表示します。Transformモードのプロキシノードへ他の機器(接続先のNMOSノード等)からアクセスさせる必要があるため、「プライベート」「パブリック」両方にチェックを入れてください。

扱うのはメタデータのみ

このツールが処理するのはIS-04/IS-05の制御プレーン情報(センダー/レシーバーの登録情報、SDP、接続状態)のみです。実際の映像/音声ストリームはこのツールを経由せず、送信元から受信先へ直接流れます。

連鎖ミラーガードは既定オフ

あるリソースが、別のレジストリからこのツール自身がミラーした結果として存在しているだけの場合にそれを選択させない「連鎖ミラーガード」は、既定では無効です。多段ミラー構成を組む場合は設定から有効化を検討してください。
