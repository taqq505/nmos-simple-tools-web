概要

シンプルなNMOSコントロール

NMOS Simple Controllerは、IS-04リソースとIS-05コネクションを管理するための軽量ブラウザインターフェースです。大規模なNMOSオーケストレーションプラットフォームを必要とせず、日常的な運用に特化したシンプルで高速な操作画面を提供します。

デバイスの素早いディスカバリー、明確なコネクション状態の表示、予測可能なIS-05動作を重視した設計です。

主な機能

  • Stream Deckボタンからワンタッチでコネクションを切り替え
  • IS-04レジストリ連携 — センダー・レシーバーを自動検出
  • 任意のセンダー・レシーバーの組み合わせを任意のボタンに割り当て
  • Stream DeckのLCDキーにコネクション状態をライブ表示
  • NMOS Simple BCCと併用可能
  • すべてのElgato Stream Deckモデルに対応

クイックスタート

Stream Deckにインストール

01

プラグインをダウンロード

GitHub Releasesページから最新の.streamDeckPluginファイルをダウンロードします。

02

Stream Deckソフトウェアからインストール

ダウンロードしたファイルをダブルクリックすると、Elgato Stream Deckソフトウェアが自動的にプラグインをインストールします。

03

IS-04レジストリを設定

プラグイン設定画面でNMOS Query APIのエンドポイントを入力します。利用可能なセンダー・レシーバーが自動的に検出されます。

04

コネクションをボタンに割り当て

NMOS Simple ControllerアクションをStream Deckのボタンにドラッグし、接続するセンダーとレシーバーを選択します。ボタンを押すと接続が実行されます。
