Overview

Connection control in the browser

NMOS Simple BCC (Browser-based Connection Controller) is a web application for managing IS-04 / IS-05 NMOS environments. Open it in any modern browser and connect to your NMOS registry to start controlling senders and receivers immediately.

Stream Deck integration lets operators assign individual connections to hardware buttons — ideal for live production where tactile, one-touch switching is essential.

Features

  • IS-04 registry query — browse all nodes, devices, senders, receivers
  • IS-05 connection management — establish and remove connections
  • Matrix view for cross-point style connection control
  • Stream Deck integration via WebSocket bridge
  • No installation — runs entirely in the browser
  • ST 2110-7 redundancy support (legs A & B)

Quick Start

Up and running in minutes

01

Open BCC in your browser

Navigate to the tool URL. No installation or local server required — it runs entirely client-side.

02

Set your IS-04 registry endpoint

Enter your NMOS Query API base URL (e.g. http://registry.local:3211/x-nmos/query/v1.3). BCC fetches nodes, senders, and receivers automatically.

03

Select a sender and receiver

Click a sender in the left column, then click a receiver to open the connection dialog. Confirm to activate the IS-05 PATCH request.

04

(Optional) Configure Stream Deck

Install the BCC Stream Deck plugin and pair it over WebSocket. Assign sender/receiver combinations to buttons for one-touch switching during live production.
