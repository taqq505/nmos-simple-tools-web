Overview

Scan a target to discover NMOS APIs

NMOS Port Explorer is a browser-based tool that scans a target IP address or hostname across a list or range of ports to discover NMOS API endpoints — Node, Registry (Query / Registration), and Connection. For every port found, it reports protocol, supported version, live response status, and an NMOS-likelihood score.

It's especially useful when a device's port configuration is unknown, or when auditing a network for unexpected exposed NMOS services during system integration. The tool always displays a reminder to use it only on systems you own or are authorized to test.

Features

  • Scan a target IP/hostname across a custom port list or range
  • Detects Node, Registry (Query / Registration), and Connection API endpoints
  • Reports protocol, supported IS-04 / IS-05 version, and live status per port
  • NMOS-likelihood scoring to surface the most promising results first
  • One-click open of the base URL / endpoint, or copy the URL
  • Configurable concurrency and timeout for scanning large port ranges
  • No installation — runs entirely in the browser

Quick Start

Run your first scan

01

Open Port Explorer in your browser

No installation required — just navigate to the tool URL.

02

Enter the target

Type the IP address or hostname of the device you want to scan.

03

Configure the ports

Enter a comma-separated port list, or switch to a range. Adjust NMOS Settings and Performance Settings if needed.

04

Start the scan and review results

Click "Start Exploration" to see protocol, version, and status for every discovered endpoint. Use the links on each row to open the base URL, open the endpoint, or copy its URL.
