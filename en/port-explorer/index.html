Overview

Inspect your IS-04 resources

NMOS Port Explorer is a browser-based IS-04 resource inspector. Point it at an NMOS Query API and immediately browse the full resource tree — nodes, devices, senders, receivers — with all associated parameters exposed.

SDP payload inspection makes it especially useful for troubleshooting ST 2110 stream configurations and verifying IS-04 registration data during system integration.

Planned Features

  • Full IS-04 resource tree navigation
  • SDP payload viewer with field-level breakdown
  • Search and filter across all resource types
  • Sender / receiver parameter diff view
  • Export resource snapshots as JSON
  • No installation — browser-based
