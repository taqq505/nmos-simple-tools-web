Overview

nmos-cpp configuration, simplified

NMOS Simple RDS Studio is a Windows system-tray application that provides a GUI for managing nmos-cpp NMOS node settings stored in the Windows Registry. Rather than editing registry keys manually, RDS Studio presents the configuration in a structured, readable form.

Designed for Windows-based ST 2110 infrastructure where nmos-cpp is the NMOS node implementation. Simplifies initial deployment and ongoing reconfiguration without requiring registry editor access.

Planned Features

  • System tray resident — always accessible, never in the way
  • GUI editor for all nmos-cpp registry keys
  • Node identity configuration (label, description, tags)
  • Registry path and IS-04 endpoint settings
  • Import / export configuration profiles
  • Windows 10 / 11 compatible
