Overview

Multicast address planning for ST 2110

MMAM (Media Multicast Address Manager) is a Docker-based web application for planning and tracking multicast address allocations across ST 2110 IP media networks. It provides a centralised view of your multicast address space, making it easy to allocate addresses, track which streams are assigned where, and avoid conflicts.

IP address planning is one of the most error-prone aspects of ST 2110 deployment. MMAM turns a spreadsheet-based process into a structured, queryable system.

Features

  • Visual multicast address range management
  • Allocate and label addresses per stream or group
  • Conflict detection — prevents duplicate assignments
  • Docker-based — deploy anywhere in minutes
  • Export allocation tables for documentation
  • ST 2110 subnet structure awareness

Quick Start

Deploy with Docker in minutes

01

Clone the repository

Clone the MMAM repository from GitHub to your local machine or server.

02

Configure your subnet

Copy .env.example to .env and set your ST 2110 multicast address range and subnet parameters.

03

Start the container

Run docker compose up -d. MMAM starts a web server on port 3000 (configurable).

04

Open in your browser

Navigate to http://localhost:3000. Add your multicast ranges and start allocating addresses to streams.
