Background

NMOS Simple Tools is a set of open-source utilities built to fill the gap between enterprise NMOS solutions and day-to-day broadcast engineering workflows.

Each tool is designed around a specific real-world problem: browser-based connection control, hardware switching via Stream Deck, resource inspection, node configuration, and IP address planning — all without requiring complex infrastructure or commercial software.
